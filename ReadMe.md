# Java DSA Practice

Welcome to the **Java DSA Practice** repository! This is a collection of data structures and algorithms (DSA) problems and solutions implemented in **Java**. The goal of this repository is to strengthen problem-solving skills and prepare for technical interviews at top tech companies.

---

## 📚 Learning Source

All concepts and problem solutions in this repository are based on the **Data Structures & Algorithms Bootcamp by Kunal Kushwaha** on YouTube.

📺 **Course Playlist:** [DSA Bootcamp by Kunal Kushwaha](https://www.youtube.com/playlist?list=PL9gnSGHSqcnr_DxHsP7AW9ftq0AtAyYqJ)

This playlist covers DSA from scratch using Java, including:

- Core Java basics
- Functions & recursion
- Sorting & searching
- Arrays and ArrayLists
- Linked Lists, Trees, Graphs
- Stacks, Queues, Heaps, Hashing
- Dynamic Programming
- Backtracking and Bitwise operations

It’s beginner-friendly and perfect for building a rock-solid DSA foundation using Java.

---

## 🚀 Features

- Implementations of fundamental data structures:
  - Arrays, Strings, ArrayLists
  - Linked Lists, Stacks, Queues
  - Trees, Graphs, HashMaps
- Algorithms for:
  - Sorting and Searching
  - Recursion and Backtracking
  - Greedy Algorithms
  - Dynamic Programming
- Problems sourced and inspired by **LeetCode**, **HackerRank**, and **Codeforces**
